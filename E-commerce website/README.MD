# 🛒 E-Commerce Website

A modern and responsive **E-Commerce Website** built using **HTML, CSS, and JavaScript**.
This project provides a clean and user-friendly shopping experience with a responsive layout, 
product showcase, and interactive user interface.

## 🚀 Features

* 🏠 Responsive Home Page
* 🛍️ Product Showcase Section
* 🔍 Search Bar
* 📂 Category Navigation
* 📱 Mobile-Friendly Design
* 🎨 Modern and Clean UI
* 💬 Customer Testimonials
* 📞 Contact Section

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and Responsive Design
* **JavaScript (ES6)** – Interactive Features

## ▶️ Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-PRADEEPMAURYA0802/E-Commerce-Website.git
   ```

2. Open the project folder.

3. Run the project by opening `e-commerce.html` in your browser.

> You can also use the **Live Server** extension in VS Code for a better development experience.
