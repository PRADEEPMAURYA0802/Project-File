# 🕒 Digital Clock

A simple and responsive Digital Clock built using HTML, CSS, and JavaScript. It displays the current time in real-time with a clean and modern user interface.

## 📸 Project Images

![Digital Clock](Digital image.jpg)

## ✨ Features

- Real-time Digital Clock
- Hours, Minutes, and Seconds Display
- Responsive Design
- Clean and Modern UI
- Easy to Use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in any web browser.
