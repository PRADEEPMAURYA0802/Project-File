# 🕒 Clock

A simple and responsive Analog Clock built using HTML, CSS, and JavaScript. It displays the current time in real-time with a clean glassmorphism design.

## 📸 Project Images

![Clock](clock image.jpg)

## ✨ Features

- Real-time Analog Clock
- Smooth Hour, Minute, and Second Hands
- Responsive Layout
- Attractive Background Image

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click index.html or open it in your browser.
