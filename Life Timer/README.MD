# ⏳ Life Timer

A simple and interactive **Life Timer** web application built using **HTML, CSS, and JavaScript**.
Users can enter their date of birth and see their age updating in real time in years, months, days, hours, minutes, and seconds.

## 🚀 Features

- 📅 Enter Date of Birth
- ⏱️ Real-time Age Calculation
- 💾 Saves Date of Birth using Local Storage
- ⚙️ Toggle Settings Panel
- 📱 Responsive Design
- 🏔️ Beautiful Background Image

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Download or Clone the repository.
2. Open the project folder.
3. Open `life.html` in your browser.
4. Select your Date of Birth.
5. Click **Add DOB** to start the Life Timer.
